# 猫骑士屠龙 · Kitten Knight vs Dragon（Three.js 3D 游戏）

v4：新主角换成混元多视图（剑+盾）模型，并已程序化绑骨骼 + 烘焙动画（`models/rig.py`：20 骨骼，待机/走路/劈砍/翻滚/跳跃/格挡 6 片段，游戏内 AnimationMixer 驱动；加载失败依次回退静态模型、几何猫）。

v2：按原片（LibTV《小猫屠龙》）逐帧重做——主角是穿银甲、戴粉蝴蝶结的
奶油色小奶猫，对手是雾原上满身尖刺、胸口燃着火核的黑龙，场景是阴天
浓雾里的绿色草原，猫身边漂浮金色星火，圣剑第三连斩爆发金光。

## 运行

双击 `index.html` 即可（单文件，约 800KB，原片 BGM、草地贴图、主视觉
海报都已内嵌，无需其他文件；需要联网加载 Three.js CDN）。
也可起本地服务器：`python3 -m http.server 8901` 后打开 localhost:8901。

## 玩法

| 操作 | 按键 |
|---|---|
| 移动 | W / A / S / D |
| 疾跑 | Shift |
| 挥剑（三连斩，第 3 剑圣光爆发，打头暴击） | J 或鼠标左键 |
| 举盾格挡（减伤 82%，耗体力） | K 按住 或 鼠标右键按住 |
| 翻滚闪避（无敌帧） | 空格 |
| 跳跃 | L |
| BGM 开关 | 左上角按钮（首次按键/点击后播放） |

移动端有 ⚔️ / 🛡️ / 💨 / 🦘 触屏按钮。

## 恶龙 AI（雾原黑龙 · 伊格尼斯，1000 HP）

火焰吐息（胸口火核变亮即预警）/ 火球三连 / 撕咬 / 尾扫 / 升空俯冲，
血量 70% / 38% 后进入狂怒与垂死狂暴阶段。

## 素材（assets/）

- `bgm.mp3`：从用户提供的原片视频提取的原音轨（27 秒，循环播放，
  已 base64 内嵌进 index.html）
- `cat-knight-sheet.webp` / `dragon-sheet.webp`：生图模型按原片抽帧
  生成的角色三视图设定图，3D 模型按此搭建
- `key-visual.webp`：主视觉海报（结算画面背景）
- `grass.jpg`：生图生成的草地纹理（已内嵌）
- 3D 模型本身仍为 Three.js 几何体程序化拼装（猫的毛发质感为程序纹理）

## 技术

Three.js 0.160（CDN importmap）；浓雾 FogExp2、阴天漫射光、实例化草丛、
粒子（喷火/火花/金色星火）、屏幕震动、伤害飘字、连斩系统；
音效（挥剑/格挡/龙吼/喷火）为 Web Audio 合成，BGM 为原片音轨。
